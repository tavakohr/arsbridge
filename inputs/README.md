# inputs/

Your workspace. Everything you put here is **ignored by git by default** —
`inputs/*` is deny-all, so a sponsor document copied in under any name cannot
be swept into a commit. Use the folder freely for real study material.

Only two files are tracked:

| File | What it is |
|---|---|
| `README.md` | this file |
| `adam_spec_CDSC-ALZ-201.xlsx` | ADaM specification for the training study, derived from `{pharmaverseadam}` metadata (public CDISC pilot data, Apache-2.0). Regenerated by `data-raw/build_example_bundle.R`. |

## The training study

The full CDSC-ALZ-201 example — a synthetic Alzheimer study on the public
Xanomeline pilot data — ships **inside the package**, not in this folder:

```r
arsbridge_example()                          # list the bundled files
arsbridge_example("annotated_shell.docx")    # annotated TLF shell (Word)
arsbridge_example("annotated_shell.xlsx")    # annotated TLF shell (Excel)
arsbridge_example("adam_spec.xlsx")          # the same spec as above
arsbridge_example("ADaM.zip")                # pharmaverseadam datasets (.xpt)
```

To work with the data here, unzip it into the conventional spot:

```r
dir.create("inputs/ADaM", showWarnings = FALSE)
unzip(arsbridge_example("ADaM.zip"), exdir = "inputs/ADaM")
```

(`inputs/ADaM/` is gitignored too.) Then the whole chain runs offline:

```r
spec_to_ars(
  shell_path     = arsbridge_example("annotated_shell.xlsx"),
  adam_spec_path = "inputs/adam_spec_CDSC-ALZ-201.xlsx",
  output_path    = "outputs/reporting_event.json"
)
ard <- ars_to_ard("outputs/reporting_event.json", adam_dir = "inputs/ADaM")
ars_fill_shell(
  shell_path  = arsbridge_example("annotated_shell.xlsx"),
  ars         = "outputs/reporting_event.json",
  ard         = ard,
  output_path = "outputs/filled_shells.xlsx",
  adam_dir    = "inputs/ADaM"
)
```

Or drive it from the app: `ars_workflow("outputs/my_study")`.

## House rule

Never commit study material from this folder. To add a genuinely shareable
file, allowlist its exact name in `.gitignore`; to commit one deliberately,
`git add -f` it — and think twice first.
